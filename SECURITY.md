# Security Policy

## Reporting a vulnerability

KeyChat handles cryptographic operations and encrypted messaging. If you discover a security vulnerability, please report it via [GitHub Security Advisories](https://github.com/meyer-pidiache/keychat/security/advisories/new).

Please do **not** report security vulnerabilities through public GitHub issues.

## What to include

- Description of the vulnerability
- Steps to reproduce
- Potential impact
- Suggested fix (if any)

You should receive a response within 48 hours.
