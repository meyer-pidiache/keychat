Arquitectura de KeyChat

KeyChat tiene un diseño de doble cara: FreeBasics (sin JS) y acceso directo (con todas las funcionalidades).

Componentes del Servidor

  • Relay WebSocket: NIP-01 para clientes Nostr
  • REST Bridge: Endpoints HTTP para FreeBasics y PWA
  • Páginas Educativas: 5 páginas HTML sin JavaScript
  • FreeBasics Detection: Detecta proxy y bifurca contenido
  • SQLite: Almacenamiento con TTL de 24 horas
  • Rate Limiter: 100 eventos/hora por IP

Componentes del Cliente

  • PWA Offline: generación de claves, cifrado/descifrado
  • Web Crypto API: ChaCha20-Poly1305, ECDH
  • Service Worker: funcionamiento offline completo
